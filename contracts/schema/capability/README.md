# capability/ — 能力声明 Schema（[contracts/DESIGN.md](../../DESIGN.md) §3 / D6；2026-09-07 端点语义重定）

**算力提供者是「端点」而非「终端」**：不收集型号类配置细节，以模型清单 + 队列/水位状态 + 运行时测量描述端点。

| 面 | 内容 | 上报通道 |
|---|---|---|
| 静态 | 可服务模型清单（`/storage` 产物键；引擎兼容性 / 端口形状由模型元数据承载） | 注册 + 心跳全量（V6） |
| 动态·调度 | per-model 队列余量（任务数；每模型配置静态上限） | 心跳 + 完成上报 |
| 动态·部署 | 终端级显存水位（后续用于自动拉取模型部署） | 心跳 |
| 运行时指标 | 分段耗时：`queue_wait` / `download` / `infer` / `upload` | 完成上报 |

- 消费方：server 检视（模型引用 ∈ 清单）· 注入反压（余量）· 部署决策（水位）· 调度打分（指标，P3）· 耗时下限校验（security §2）
- 版本号规则**已定（V2）**：`version` 整数字段，每域独立递增
- 字段命名与粒度待 submodule 就位后对照模型元数据收口
- **已废止**：并发容量字段（队列模型替代）、引擎类型/端口形状端点级声明（并入模型元数据）、每模型显存（改终端级水位）
