# control-channel/ — 控制通道 API 契约（根 [DESIGN.md](../../../DESIGN.md) §3 / V5/V6）

控制通道（TS 侧实现；REST + WS 推送，轻量 JSON）：

- **REST**：
  - 注册（机器凭证，V3 强制鉴权）
  - 心跳（**全量携带**：可服务模型清单 + per-model 队列余量 + 终端级显存水位，V6，默认 30s / TTL 90s）
  - 完成上报（输出 URI + 形状/类型元数据 + 难度系数 + 错误码 + **分段耗时** `queue_wait`/`download`/`infer`/`upload`，D8 事件驱动）
  - 工作流状态
- **WS 单向推送**：
  - 「执行节点」任务下发（任务键 + 模型引用 + 输入 URI + 输出上传目标 + **优先级标志**：失败重派任务带补偿优先级）
  - **任务撤销标记**（声明该任务不再执行；端点出队前检查，已标记则跳过取下一个——标记式懒惰撤销）
- 端点：client（纯 C++ Poco REST/WS 客户端）↔ server 控制面
- 与数据面（对象存储总线，张量 URI 交互）**不可混用**
